# Basis of the Scenario

Required by the [primary brief](MIS215_TermProject_Brief.pdf), §3.1–3.4 pp. 4–6 and proposal §8 pp. 15–16. **Bicol Learning Academy is fictional**, modeled as a school in the Bicol Region whose borrowers and equipment custodian share a central equipment register. No claim is made that a real school has adopted or approved these rules.

## Source register

1. [DepEd SDO Valenzuela ASSETS description](https://sites.google.com/deped.gov.ph/assetmanagement/s/assets): published school-division property unit description of equipment issuance tracking and borrowing/returning/transfer forms. It establishes a relevant real practice, not a Bicol location or student reservation policy.
2. [DepEd Order 001 s. 2023](https://www.deped.gov.ph/wp-content/uploads/2023/01/DO_s2023_001.pdf): published roles/forms for property accountability. It supports a custody/accountability context, not the proposed application's complete approval state machine.
3. [DepEd SDO Zambales Library Hub borrowing and return procedure](https://zambales.deped.gov.ph/citizens-charter/borrowing-and-returning-lr-from-lh.html) describes requesting supplementary learning resources, agreed return dates and staff inspection and inventory of returns. It is an analogue for school resource lending.
4. [Original EquipTrack request](PROJECT_REQUEST.md) defines the five transactions and roles for the fictional school.

## Transaction-to-practice traceability

| Transaction | Present documentary basis | Remaining grounding / design assumptions |
|---|---|---|
| T1 Availability | Tracking issued equipment and custody in ASSETS | How an equivalent school exposes item availability to student/faculty borrowers; period reservation definition |
| T2 Request | ASSETS describes borrowing/forms generally | Actual request fields, student/faculty eligibility and owner cancellation practice need a suitable published borrowing form/procedure or consented analogous-staff interview |
| T3 Approval | Accountability roles/forms in the DepEd order | Direct evidence of equipment-loan approval/rejection authority and review flow is still needed; the user's custodian design is not proof of institutional policy |
| T4 Release | Published issuance/custody forms and assigned property roles | Match a source to release acknowledgment/inspection details; don't equate permanent property assignment automatically with a short-term loan |
| T5 Return | ASSETS describes returning and a Return Slip | Exact return inspection, damage routing and maintenance handling need supporting procedure or clearly identified proposed improvement |

The brief requires realistic processes grounded in sources; merely labeling invented rules as assumptions does not complete that requirement. The current sources provide **partial**, broad grounding. Add direct procedure/form evidence for the exact lending workflow before claiming the proposal's scenario basis is complete.

Booking interval constraints, exclusive active custody and atomic audit updates are technical implementation choices. Distinguish them from organizational authorization, deadlines and eligibility rules. Where proposing an improvement, state the documented baseline and the rationale for the proposed change instead of attributing it to an existing school.

Use only public process information or appropriately consented requirements information; no real client/student records, copied live screens or integration with existing school systems. The brief allows a fictional case without an organization permission letter; topic/protocol approval by the FIC remains separate and is not established here. Final proposal/report references must be formatted and verified in APA 7.
